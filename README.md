# Extending-Overriding
## Project Description
C# console application that demonstrates inheritance and method overriding. Utilizing 3 separate files: program.cs, animal.cs, cat.cs. 
Animal class is the base class, while Cat class inherits from animal and adds its own property and overridden method

## Project Skills
  - Inheritance in C#
  - Creation of base classes and derived classes
  - Constructors used for initializing object properties
  - Public Get & Set properties
  - Keywords: override & virtual
  - Understand how a derived class can reuse and extend functionality from a base class

## Developmental Process
Incremental development process - I created each class separately, added required properties & methods, then tested the application
through the main program. Testing the original and updating values to make sure that inheritance & overriding worked properly.
